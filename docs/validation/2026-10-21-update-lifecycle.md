# 更新退出与进度验证

实现边界见 [架构文档](../../ARCHITECTURE.md)，变化见 [变更日志](../../CHANGELOG.md)，导航见 [文档索引](../README.md)。

## 根因与修复

- 真实 SwiftUI 更新弹窗使用 `interactiveDismissDisabled(true)`，未解除附着时会阻止 AppKit 退出。只延后退出或直接调用 `endSheet` 仍可失败：SwiftUI 绑定保持显示时，弹窗可能继续附着。
- 更新任务原来挂在弹窗自身，关闭弹窗也会取消任务。现在任务由设置页持有，设置显示绑定为关闭，并等待窗口解除附着后才交换应用目录、请求退出；真正拒绝退出时仍超时回滚。
- GitHub API 的 403/429 备用路径只请求 HEAD，构造的版本对象正文为空。现补读官网 Atom 订阅，严格匹配该版本的链接并提取纯文本。
- completion-handler 形式的下载没有触发此前设置的 download delegate 回调。现观察任务实际接收字节数，保留落盘下载、大小限制、取消和节流；不使用任务默认的 100 个工作单位冒充字节。

## 自动验证

- 80 项 App 测试（18 套）通过，包括正文备用来源、版本匹配、数字零值、下载限制及退出回滚。
- `python3 -m unittest discover -s Tests/UpdateLifecycle -v`：1 项真实窗口生命周期测试通过。测试独立编译生产代码并运行临时应用，确认弹窗先附着、旧进程退出、应用目录替换、新进程写回启动标记、旧版备份保留。测试关闭剪贴板记录，使用临时目录，不注册用户服务或广播配置。
- Release 构建、文档门禁、差异检查和目录隐私检查在交付前执行。

## 实际网络探针

使用生产 `UpdateChecker` 和 `UpdateInstaller.prepare` 下载公开发布包到独立临时应用：

- 获取 `v0.0.4`，更新正文 616 字符；官网 Atom 内容也已核对。
- 下载显示实际字节数与连续百分比，最终为 4,618,115 字节、100%。
- 随后完成 SHA-256 校验、安全解压及应用签名验证；临时准备目录已清理。

网络下载与真实退出重启分别验证，未将下载到的公开版本替换进用户应用。未验证 Intel 真机、GitHub 长时间断网后恢复或新版启动后崩溃自动恢复；最后一项仍沿用保留备份的边界。
