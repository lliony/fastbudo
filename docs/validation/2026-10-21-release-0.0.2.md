# 0.0.2 发布验证

版本范围见 [变更日志](../../CHANGELOG.md)，构建方式见 [README](../../README.md)，导航见 [文档索引](../README.md)。

- 主应用与 Finder 扩展：版本 0.0.2，构建号 2。
- Apple Silicon：75 项 App 测试（18 个测试套件）、19 项 Bridge 测试、1 项独立进程复制内存回归测试通过；Release 构建通过。
- 256 MiB 复制回归探针峰值 RSS 为 8,503,296 字节，不代表主应用常驻内存。
- Intel：通用 Mac 目标交叉编译 Release 通过；本机无 Intel 运行目标，未执行 Intel 测试或真机验收。
- 两种安装包均检查主应用、Finder 扩展、7zz、7z.so、ArchiveBridge 的 Mach-O 架构与最低部署版本：arm64 / macOS 27.0，x86_64 / macOS 14.0。
- 两份应用通过 `codesign --verify --deep --strict`；Finder 扩展保留沙箱 entitlement。使用临时签名，未进行开发者签名或公证。
- 更新器按编译架构选择发布 ZIP 并验证目标架构；新增资产名回归测试。未验证真实跨版本联网下载安装全流程。
- 文档门禁、相对链接与 `git diff --check` 通过。

Xcode 与性能探针首次在受限沙箱内无法使用测试服务或编译缓存，允许对应本地工具访问后重跑通过。Intel 指定本机运行目标失败后改用通用目标交叉编译；这不构成 Intel 运行验证。

本轮未重测 Finder 各视图、网络卷、辅助功能授权、低空间磁盘映像场景及长期泄漏；不自动替换用户当前安装的应用。发布附件包括两种 ZIP、同提交源码包与 SHA256SUMS.txt，源码包包含固定第三方源码及构建脚本。
