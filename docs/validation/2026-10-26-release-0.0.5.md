# 0.0.5 发布验证

变更见 [变更日志](../../CHANGELOG.md)，构建与兼容边界见 [README](../../README.md)，导航见 [文档索引](../README.md)。

- 界面改动接入远端已清理历史的 main，保留许可证补齐和剪贴板修复；不合并旧历史，不更改仓库可见性。
- 主应用与 Finder 扩展均为 0.0.5，构建号 5；应用图标保持原样。
- Apple Silicon / macOS 27.0.1：80 项 App 测试（18 套）、19 项 Bridge 测试、1 项独立进程复制内存回归测试、6 项 Repository 检查和 1 项真实更新窗口生命周期测试通过。
- 四个设置分类经独立原生预览检查；纵向分组、行尾开关、数值输入布局、页面滚动和固定状态栏正常。采集与服务未在预览中启动。
- arm64、x86_64 Release 构建通过。分别核对主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge：均只有对应目标架构；ARM 最低 macOS 27.0，Intel 最低 macOS 14.0。
- 双架构应用内的 MIT、第三方声明、7-Zip 许可摘要与 LGPL 完整正文均与仓库源文件逐字节一致。
- 引擎、扩展、主应用由内向外临时签名，扩展保留沙箱 entitlement；安装 ZIP 解包后的严格嵌套签名和目录隐私检查通过。未经 Apple 公证。
- 对应源码使用同版本提交导出，包含固定版本的 7-Zip 源码、许可证与构建脚本；与两种架构 ZIP 一并提供 SHA256SUMS.txt 校验清单。

发布附件：`FastBudo-0.0.5-macOS-arm64.zip`、`FastBudo-0.0.5-macOS-x86_64.zip`、`FastBudo-0.0.5-source.tar.gz` 和 `SHA256SUMS.txt`。发布是否完成以 GitHub Release 及附件核验为准。

Intel 仅交叉编译，未做真机验收。本轮未验证 Finder 权限交互、真实跨版本联网更新、VoiceOver 朗读和长期运行；更新生命周期测试使用专用临时应用，不等同于正式版联网更新。未替换本机正在运行的应用。
