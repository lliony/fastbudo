# 0.0.11.beta 发布验证

变更见[变更日志](../../CHANGELOG.md)，构建与兼容边界见[项目说明](../../README.md)，导航见[文档索引](../README.md)。

## 发布范围

- 0.0.11.beta 是 0.0.11 的 beta 预览，本轮无功能改动：以当前 0.0.10 代码为基础，仅将版本号升为 `0.0.11.beta`、构建号 `11`，重新构建并发布，供站点手动下载提前验证公开分发链路。
- 主应用与 Finder 扩展均为 0.0.11.beta，构建号 11。
- 因更新检查器只接受三段正式版号（`App/UpdateChecker.swift`），0.0.11.beta 不进入应用内自动更新，仅通过 Gitee Releases / 官网下载页提供。

## 构建与自动验证

- 固定第三方引擎构建通过；19 项 Bridge 测试通过；162 项 App 测试（21 套）通过（TEST SUCCEEDED）。
- Apple Silicon Release 构建通过。主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge 均为 arm64，最低 macOS 27.0。
- Intel Release 交叉编译通过（`MACOSX_DEPLOYMENT_TARGET=14.0` 构建引擎、`ARCHS=x86_64`）。主应用、Finder 扩展和三项内置引擎均为 x86_64，最低 macOS 14.0；完成后已恢复 ARM 开发引擎。
- 两种应用包的主应用与扩展版本均为 0.0.11.beta / build 11；MIT、第三方声明、7-Zip 许可摘要及 LGPL 正文与仓库源文件一致。
- 内置引擎、Finder 扩展和主应用由内向外临时签名；Finder 扩展保留沙箱 entitlement，严格嵌套签名和解包后隐私检查通过。未经 Developer ID 签名或 Apple 公证。

## 验证边界

- Intel 仅交叉编译，未做真机验收。
- 0.0.11.beta 与 0.0.10 功能等价，未重复全套功能回归；仅重新构建并核对了版本号、双架构与内置引擎。
- 开发者签名、公证、长期驻留、Gitee 匿名下载限流及跨版本回滚不在本轮验证范围；beta 包不进入应用内更新链路。
