# 0.0.8 发布验证

变更见[变更日志](../../CHANGELOG.md)，构建与兼容边界见[项目说明](../../README.md)，导航见[文档索引](../README.md)。

## 发布范围

- 主应用与 Finder 扩展均为 0.0.8，构建号 8。
- 截图标注工具条图标放大并收紧间距，工具条紧贴图片右下角，不再与图片边缘留出空隙。
- 截图标注按标注版本缓存整图渲染、画布用显示分辨率副本，大图连续复制、保存和贴图的内存峰值下降。
- 贴图关闭统一释放视图与列表引用，长期运行不再残留已关闭贴图的视图环。
- 区域截图完成后面板所有权随结果显式转交，取消或未用于编辑时及时关闭，坐标换算统一。
- 剪贴板历史排序与清理改为数据库列查询，复制大图时不再长时间占用全局锁，旧库自动迁移。
- 压缩引擎读取密码前异常退出时按任务失败处理，不再因管道信号退出。
- 更新检查的网页回退收到 404 时明确提示更新源可能为私有或暂无正式版本，不再误报为可稍后重试的普通服务故障。

## 构建与自动验证

- 固定第三方引擎构建通过；19 项 Bridge 测试通过；1 项 256 MiB 复制内存回归测试通过（探针峰值 RSS 10,567,680 字节）。
- Apple Silicon Release 构建通过。主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge 均为 arm64，最低 macOS 27.0。
- Intel Release 交叉编译通过。主应用、Finder 扩展和三项内置引擎均为 x86_64，最低 macOS 14.0；完成后已恢复 ARM 开发引擎。
- 两种应用包的主应用与扩展版本均为 0.0.8 / build 8；MIT、第三方声明、7-Zip 许可摘要及 LGPL 正文与仓库源文件一致。
- 内置引擎、Finder 扩展和主应用由内向外临时签名；Finder 扩展保留沙箱 entitlement，严格嵌套签名和安装产物隐私检查通过。未经 Developer ID 签名或 Apple 公证。
- 项目标准门禁、文档相对链接、暂存区隐私路径及差异格式检查通过。

## 验证边界

Intel 仅交叉编译，未做真机验收。真实多显示器混合缩放、长期驻留、Developer ID 签名、公证及匿名私有仓库更新不在本轮验证范围；自动测试和本机探针不能替代这些验收。App 测试（xcodebuild test）因当前环境无法创建测试 runner 伪终端而未能运行，仅记录为环境边界，不作为验证断言通过依据。
