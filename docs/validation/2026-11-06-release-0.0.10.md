# 0.0.10 发布验证

变更见[变更日志](../../CHANGELOG.md)，构建与兼容边界见[项目说明](../../README.md)，导航见[文档索引](../README.md)。

## 发布范围

- 主应用与 Finder 扩展均为 0.0.10，构建号 10。
- 截图文字标注默认透明背景、不显示边框；文字按盒宽自动换行、高度自适应完整内容；提交后可点击文字内容区整体移动，拖右下角缩放；工具栏可开启“文字边框”并设置宽度。
- 修复系统开启“显示器各自使用独立 Space”时，区域截图遮罩只在主屏可用的问题；每块屏幕各建一个选区窗口，副屏可选择和截图。

## 构建与自动验证

- 固定第三方引擎构建通过；19 项 Bridge 测试通过。
- 162 项 App 测试（21 套）通过；文字标注的盒子移动与缩放测试覆盖了原图像素和画布坐标换算。测试辅助函数 `AppTests/ImageEditorTests.swift` 修正了未上屏窗口合成事件的 flipped 坐标换算，应用实现逻辑未改。
- Apple Silicon Release 构建通过。主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge 均为 arm64，最低 macOS 27.0。
- Intel Release 交叉编译通过（`ARCHS=x86_64`、`MACOSX_DEPLOYMENT_TARGET=14.0`）。主应用、Finder 扩展和三项内置引擎均为 x86_64，最低 macOS 14.0；完成后已恢复 ARM 开发引擎。
- 两种应用包的主应用与扩展版本均为 0.0.10 / build 10；MIT、第三方声明、7-Zip 许可摘要及 LGPL 正文与仓库源文件一致。
- 内置引擎、Finder 扩展和主应用由内向外临时签名；Finder 扩展保留沙箱 entitlement，严格嵌套签名和解包后隐私检查通过。未经 Developer ID 签名或 Apple 公证。
- 项目标准门禁、文档相对链接、暂存区隐私路径及差异格式检查通过。

## 更新验证

0.0.9 → 0.0.10 的手动或自动更新链路未在本轮重新执行；更新实现与下载校验路径未改。发布后应使用公开 Gitee Release 的 SHA-256 清单核对两种安装包，并在 Apple Silicon 实机确认首次启动与更新提示。

## 验证边界

- Intel 仅交叉编译，未做真机验收。
- 多显示器独立 Space 的区域截图修复有代码和自动测试依据，但未在混合缩放、多屏排列差异下做真机回归；真实窗口生命周期也未在本轮重新执行。
- 自动测试使用合成鼠标事件，不能替代真实截图编辑器中的字体渲染、辅助功能权限和拖动手感验收。
- 开发者签名、公证、长期驻留、Gitee 匿名更新限流及跨版本回滚不在本轮验证范围。
