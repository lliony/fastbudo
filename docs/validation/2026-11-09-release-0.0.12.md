# 0.0.12 发布验证

变更见[变更日志](../../CHANGELOG.md)，构建与兼容边界见[项目说明](../../README.md)，导航见[文档索引](../README.md)。

## 发布范围

- 0.0.12 为正式版，主应用与 Finder 扩展均为 0.0.12，构建号 12；应用内更新链路恢复（更新检查器接受三段正式版号）。
- 相对 0.0.11.beta 的功能变化：更新检查改拉发行列表并修复预发布误报；官网下载页改分发 dmg；区域/全屏截图可截到右键菜单与浮窗（冻结帧）；剪贴板同内容去重合并；修复 Finder 新建后不自动进入原地重命名；贴图工具条贴图片下方外侧、新增关闭按钮与 ESC、窗口贴合图片透明无白边、Retina 逐像素渲染。

## 构建与自动验证

- 固定第三方引擎构建通过；19 项 Bridge 测试通过；174 项 App 测试（21 套）通过（TEST SUCCEEDED）。
- Apple Silicon Release 构建通过。主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge 均为 arm64，最低 macOS 27.0。
- Intel Release 交叉编译通过（`MACOSX_DEPLOYMENT_TARGET=14.0` 构建引擎、`ARCHS=x86_64`）。主应用、Finder 扩展和三项内置引擎均为 x86_64，最低 macOS 14.0；完成后已恢复 ARM 开发引擎。
- 两种应用包的主应用与扩展版本均为 0.0.12 / build 12。
- 安装包由内向外 ad-hoc 签名（内置引擎 → Finder 扩展保留沙箱 entitlement → 主应用），两架构 zip 与 dmg 均通过 `codesign --verify --deep --strict`；dmg 挂载核对版本与架构一致，解包 zip 后 `check-private-paths.py --artifact` 通过。未经 Developer ID 签名或 Apple 公证。

## 验证边界

- Intel 仅交叉编译，未做真机验收。
- 当前仅在 Apple Silicon / macOS 27 实测；0.0.11.beta 升级到 0.0.12 的应用内更新链路未实测（本次为 0.0.11.beta 安装包发布后的首个正式版，更新元数据待发布后线上核对）。
- 贴图工具条位置/关闭与 Retina 渲染在开发机完成安装重启，未做完整实机回归；右键菜单/浮窗截图冻结帧的实机验证见[验证记录](2026-11-09-screenshot-frozen-capture.md)（单元已加，实机待验）。
- 开发者签名、公证、长期驻留、Gitee 匿名下载限流及跨版本回滚不在本轮验证范围。
