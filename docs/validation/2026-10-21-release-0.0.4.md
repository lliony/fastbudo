# 0.0.4 发布验证

变更见 [变更日志](../../CHANGELOG.md)，构建见 [README](../../README.md)，导航见 [文档索引](../README.md)。

- 隐私修复合并到 main，并保留更新退出保护和下载、安装进度修复。
- 主应用与 Finder 扩展均为 0.0.4，构建号 4。
- Apple Silicon / macOS 27.0.1：79 项 App 测试（18 套）、19 项 Bridge 测试、1 项独立进程复制内存回归测试及 4 项目录隐私检查测试通过。
- arm64 与 x86_64 Release 构建通过；主应用、Finder 扩展、7zz、7z.so、ArchiveBridge 均核验目标架构和最低部署版本。ARM 为 macOS 27.0，Intel 为 macOS 14.0。
- 两份应用使用临时签名，扩展保留沙箱 entitlement；严格嵌套签名检查通过，未经 Apple 公证。
- Release 移除调试符号；双架构完整应用、提交索引和同提交源码包通过目录隐私检查。安装 ZIP 解包后再次检查签名和目录隐私。
- 文档门禁、相对链接和差异空白检查通过。发布附件为双架构 ZIP、源码包及 SHA256SUMS.txt。

Intel 仅交叉编译，未作真机验收；未验证真实跨版本联网更新全流程、Finder 系统交互和长期泄漏。目录检查覆盖常见用户目录及临时目录模式，不等于通用敏感信息扫描；此前 Git 历史和旧发布附件未重写或替换。Debug 与 dSYM 保留本地，不包含在安装包内。
