# 0.0.3 发布验证

变更见 [变更日志](../../CHANGELOG.md)，构建见 [README](../../README.md)，导航见 [文档索引](../README.md)。

- `codex/clipboard-activation` 快进合入 main；其他本地分支提交已包含在 main 中。
- 主应用与 Finder 扩展版本均为 0.0.3，构建号 3。
- 合并后 Apple Silicon 测试：76 项 App 测试（18 套）、19 项 Bridge 测试和 1 项独立进程复制内存回归测试通过。
- 256 MiB 复制探针峰值 RSS 为 9,568,256 字节，不代表主应用常驻内存。
- arm64 与 x86_64 Release 构建通过；逐一核验主应用、Finder 扩展、7zz、7z.so、ArchiveBridge 的架构、版本与最低部署目标。
- ARM 包最低 macOS 27.0；Intel 包最低 macOS 14.0。Intel 仅交叉编译，未在 Intel 真机或 macOS 26 上验收。
- 两份应用通过严格嵌套签名检查，扩展保留沙箱 entitlement；临时签名，未经 Apple 公证。
- 文档门禁、相对链接及差异空白检查通过。

窗口回归测试覆盖非激活面板、键盘焦点能力、重复唤起及主动打开设置的既有行为。未实测用户报告的偶发快捷键场景，未验证真实跨版本联网安装全流程、网络卷及长期泄漏。发布附件为两种架构 ZIP、同提交源码包和 SHA256SUMS.txt；本次不替换本机已安装的修复版。
