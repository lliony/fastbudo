# 0.0.7 发布验证

变更见[变更日志](../../CHANGELOG.md)，构建与兼容边界见[项目说明](../../README.md)，导航见[文档索引](../README.md)。

## 发布范围

- 主应用与 Finder 扩展均为 0.0.7，构建号 7。
- 新增区域、窗口和全屏截图，支持基础标注、复制、保存及贴图；截图和贴图快捷键支持直接录入并保留冲突保护。
- 区域截图直接进入原位选区，保持选区明亮、外围灰显；标注工具位于图片外侧空间，选择后立即绘制，文字在图片上就地输入。
- 贴图支持直接拖动图片区域；缩放、旋转、翻转、透明度和复制按空间直显或进入“更多”，工具栏不显示穿透、隐藏和关闭按钮。
- 更新检查继续使用当前私有仓库；匿名访问仍可能失败，不把私有仓库发布等同于公开更新源。

## 构建与自动验证

- 固定第三方引擎构建通过；19 项 Bridge 测试、145 项 App 测试（21 套件）和 1 项 256 MiB 复制内存回归测试通过，合并后复测的复制探针峰值 RSS 为 9,486,336 字节。
- Apple Silicon Release 构建通过。主应用、Finder 扩展、7zz、7z.so 和 ArchiveBridge 均为 arm64，最低 macOS 27.0。
- Intel Release 交叉编译通过。主应用、Finder 扩展和三项内置引擎均为 x86_64，最低 macOS 14.0；完成后已恢复 ARM 开发引擎。
- 两种应用包的主应用与扩展版本均为 0.0.7 / build 7；MIT、第三方声明、7-Zip 许可摘要及 LGPL 正文与仓库源文件一致。
- 内置引擎、Finder 扩展和主应用由内向外临时签名；Finder 扩展保留沙箱 entitlement，严格嵌套签名和安装产物隐私检查通过。未经 Developer ID 签名或 Apple 公证。
- 项目标准门禁、文档相对链接、暂存区隐私路径及差异格式检查通过。
