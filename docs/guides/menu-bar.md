# 菜单栏收纳

> 已按用户要求移除菜单栏收纳功能。本文仅保留历史记录，不再适用于当前版本；FastBudo 原有菜单栏工具入口仍保留。

在 FastBudo 设置中进入「菜单栏」，开启「启用菜单栏收纳」。初次安装默认关闭，启用后保持展开。

按住 ⌘ 拖动菜单栏图标调整顺序。分隔标记「│」左侧是收纳区，右侧是常驻区；将收纳箭头和 FastBudo 的 ⌘ 工具入口留在右侧。点击箭头展开或收起，展开后点击原应用图标照常使用。部分系统图标不可移动。

「启动时收起」只影响下次应用启动，当前状态不随此开关立即改变。关闭后重新启用收纳功能始终从展开开始。

## 恢复显示

找不到收纳箭头时，重新打开 FastBudo 设置，进入「菜单栏」点击「展开收纳区」。也可关闭「启用菜单栏收纳」，恢复显示并移除 FastBudo 收纳控件。正常退出应用会进行同样清理；压缩任务阻止退出时收纳功能继续工作。

点窗口 × 只关闭设置页，收纳与其他后台功能继续运行。不会关闭其他应用或修改它们的设置。

## 限制与验证

采用状态栏宽占位方式收纳，不需要辅助功能或屏幕录制权限，不提供独立图标浮窗和自动排序。图标顺序由系统维护，FastBudo 不保存第三方图标坐标。

用户已确认本机原型能够收起、恢复且右侧按钮可见；正式设置页已核验启用、恢复和禁用交互。屏幕空间不足时，展开不保证能容纳全部图标。多显示器、全屏、睡眠唤醒、异常退出恢复及跨应用重启排序尚未验证；详细证据见[验证记录](../validation/2026-10-16-menu-bar.md)。
