## 截图与标注

菜单栏选择“截图 → 区域截图 / 窗口截图 / 全屏截图”。全屏菜单选择具体显示器；区域截图立即进入选区，使用箭头指针拖动选区，Escape 或右键取消；窗口截图仍使用系统窗口选取。默认 Control+Shift+S 发起区域截图。首次使用需在系统设置的“屏幕与系统音频录制”中允许 FastBudo，可能需要重启应用；设置页显示“屏幕录制 · 已启用 / 未启用”，打开页面和回到前台时刷新，仅未启用时提供系统设置入口。

区域选取完成后继续在整屏选区面板编辑：选中区域明亮，其余区域保持灰显，图片不再变成独立浮层。工具位于选区右下角；小选区允许工具显示在选区外，不拉伸图片。抓取前仍短暂隐藏遮罩，并非冻结屏幕。窗口/全屏截图仍显示独立图片浮窗；小窗口工具自动分两排。区域编辑时拖动图片只移动选区及工具，外围灰色背景不移动；窗口/全屏截图仍可拖图移动图片窗口。关闭按钮或 Escape 退出；工具面板或文字输入中一次 Escape 直接关闭当前截图，保存面板中 Escape 仅取消保存。点击画笔标注按钮后高亮并进入绘制，选项中当前工具高亮；再次点击标注按钮退出绘制、恢复拖图移动。使用矩形、椭圆、箭头、画笔、文字或马赛克，支持撤销和重做。复制、保存 PNG 和贴图均包含标注。保存面板依附当前图片窗口；复制或保存 PNG 成功后关闭图片，取消或失败保留图片。保存拒绝覆盖现有文件，请选择新文件名。区域选区中按住 Control 松开鼠标会直接复制到剪贴板，不进入编辑器；窗口截图保持系统 Control 点击语义。

选区与抓取各自等待上限 120 秒，同时最多两个编辑窗口。图片上限 20 MiB、单边 20000 像素、总计四千万像素。退出/关闭编辑器不自动保存，请先复制或另存。截图不会自动启用剪贴板记录，复制后是否入历史沿用剪贴板设置。

## 快速截图输出

菜单栏“截图”或设置页选择“截图并复制 / 截图并下载”，完成区域选取后跳过标注编辑器。复制直接写入 PNG；下载弹出原生“另存为”选择目录和文件名，确认后才保存。取消选区或保存不会产生输出；写盘失败保留图片到编辑器供重试，仍拒绝覆盖已有文件。

设置 →“截图与贴图”可分别录入这两个动作的快捷键，初始“未设置”，可清除。原截图/贴图绑定保持不变；总开关管理四种动作。录入时全部五个全局入口（含剪贴板）暂停，结束后按原状态恢复；冲突保留旧绑定。按住 Control 松开普通区域选取仍直接复制，明确选择下载时仍显示另存为。

## 贴图

Control+Shift+P 或菜单栏“贴图”读取剪贴板图片；剪贴板历史图片右键“贴到屏幕”读取原图，不更改当前剪贴板。编辑器可直接贴出标注后的图片。

拖动标题栏移动，使用窗口内按钮缩放；“操作”菜单提供旋转、翻转、复制、穿透、隐藏和关闭。透明度滑杆最小为 15%。鼠标穿透后无法点击窗口，通过菜单栏“管理贴图 → 恢复显示并取消穿透”恢复。隐藏也从该菜单恢复。最多同时 10 张贴图、合计四千万原图像素；退出后不恢复，不自动写入磁盘。

设置 →“截图与贴图”点击当前快捷键后直接按键录入；支持普通单键、数字、空格、导航键、功能键、Escape，以及 Shift / Option / Control / Command 组合。松键保存，再次点击录入按钮、失焦或离开页面取消；录入时暂停本应用全局快捷键，结束后按原启用状态恢复。冲突时保留原设置并显示原因。系统保留组合可能被系统截获，需要另选组合。单独修饰键不构成可注册的主键；全局单键可能影响日常输入。
