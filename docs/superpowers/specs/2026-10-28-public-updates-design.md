## 证据与决定

2026-10-28，本机匿名 API latest 请求返回 403 限流；官网 latest 和 releases 页面返回 404；Atom 请求发生 TLS 连接失败。已登录 gh 查询确认 lliony/fastbudo 为私有仓库，存在正式 Latest v0.0.5。现有 UpdateChecker 的 API 限流分支回退到官网 HEAD，再将 404 映射成 server(404)。UpdateInstaller 的安装包和 SHA256SUMS 也来自同一私有仓库，因此只修提示或只换 API 地址不够。

用户选择独立公开安装包仓库，源码保持私有。建议名称 lliony/fastbudo-releases，正式创建前确认名称可用和账号归属。应用匿名读取公开 API/网页/Atom/附件，不内置 GitHub 令牌、不调用用户电脑 gh 作为运行依赖。

## 发布内容与边界

公开仓库只放安装包、SHA256SUMS、版本说明及必须的许可证/第三方源码履约材料，不复制私有源码仓库历史。先准备具体文件清单并扫描隐私信息，之后再请求公开创建及上传授权。选择方案不等于本轮授权公开文件。

每个正式版本必须同时有 arm64、x86_64 ZIP，名称沿用 FastBudo-<version>-macOS-<arch>.zip。核对 ZIP 内主应用、Finder 扩展、引擎架构与版本一致，校验和、签名和最低系统版本；交叉编译不能冒称 Intel 实机验证。不得把旧的、不识别新源的 v0.0.5 安装包当作修复版发布。

## 更新行为

所有发布 URL 使用唯一常量来源，检查器返回的 tag 必须通过已有三段版本校验。保留官网路径/主机校验、下载重定向白名单、包大小限制、校验和及安装回滚。

API 或网页 404 均显示“更新源不可访问或暂无正式版本”，不能断言最新或必然无发布。403/429 继续回退官网；网络失败仍失败，不无限回退。只有成功取得有效版本并比较后才显示已是最新版。

旧版地址已固定到私有源，无法从不存在的公开入口收到迁移通知；首次手动安装修复版，后续才使用新源。发布准备未完成时，代码可测试，但不能宣称在线更新恢复。
