# 截图交互调整

依据用户本轮要求：截图只显示图片及右下角功能按钮；支持直接录入自定义快捷键；有屏幕录制权限时显示启用状态。实施见[计划](../plans/2026-10-26-screenshot-interaction.md)，入口见[文档索引](../../README.md)。本设计已在当前工作区实现，尚未更新安装版；实测范围见[使用与验证记录](../../guides/screenshot-pin.md)。

## 截图界面

调整截图完成后的编辑浮窗，系统选区阶段继续使用现有 `screencapture`。去掉窗口标题栏、上下工具栏、常驻说明和大面积空白。窗口按截图宽高比适配鼠标所在屏幕可用区域，保留源图全部像素，初始显示不放大超过该屏幕的原始显示比例。

图片右下角叠放一组紧凑按钮：标注、撤销、重做、复制、保存、贴图、关闭。标注按钮展开锚定在按钮附近的面板，放六种工具、颜色、笔宽和文字输入；不永久占用画布上下区域。小截图的按钮自动换行；窗口可为按钮保留最小可操作尺寸，不能裁掉图片。错误和导出状态临时显示在按钮上方，避免失败无反馈。

画布只处理图片中的绘制，浮动按钮/弹出面板消费自己的鼠标事件。标注数据及 PNG 渲染不包含 UI。无标题栏后增加明确关闭按钮及 Escape 关闭；文字面板打开时 Escape 先关闭面板。需要移动窗口时提供右下角拖动手柄，不让画布拖动同时移动窗口。所有图标有中文可访问名称、悬停提示和键盘焦点。

## 快捷键录入

以下为首轮规则；组合限制及 Escape 取消已由[自由录入设计](2026-10-26-unrestricted-shortcuts-design.md)取代。

只替换截图/贴图设置的固定下拉框，剪贴板原设置界面不变。点击当前组合开始录入，再按目标组合。支持包含 Control 或 Command 的普通组合，以及 F1–F20 单键/组合；纯字母、纯数字、单独修饰键不能注册，Escape 保留原设置并退出。

继续使用既有四个 UserDefaults key 和 Carbon 注册；默认仍是 Control+Shift+S / Control+Shift+P。录入期间临时暂停本应用三个全局入口，避免录入旧组合时误截图或弹出剪贴板。松键完成后恢复；失焦、切页、关闭设置和取消均恢复，不安装全局键盘监听器，也不额外请求辅助功能权限。

先校验与本应用其他已启用入口是否重复，再尝试系统注册；成功才保存组合。失败显示“快捷键已被占用或系统不支持，原快捷键已保留”，不覆盖偏好。共享注册函数先注册候选、成功后再释放旧绑定；重复提交同一组合视为成功。录入要拦截本窗口的 Command 快捷操作，不能因录入 Command+Q 而直接退出应用。系统先行截获的保留组合可能无法被录入器收到，提示另选组合，不承诺所有系统键可用。

## 权限状态

设置页通过 `CGPreflightScreenCaptureAccess()` 显示实际状态：已授权时绿色“屏幕录制 · 已启用”，未授权时“屏幕录制 · 未启用”并提供系统设置入口。打开设置页、应用回到前台、开始截图前均刷新；不轮询，不以持久化布尔值代替系统状态。

读取状态不触发授权。只有用户主动截图时沿用现有请求路径；请求后再次查询状态，仍不可用时说明可能需要重启应用。授权后首次状态显示与撤销授权后的更新均需真实系统验收，不由模拟测试代替。

## 约束与验收

Apple Silicon / macOS 27；Swift 6、SwiftUI/AppKit，无新增依赖。保留图片大小/数量上限、无覆盖保存、异步编码、主线程 AppKit 操作及现有快捷键事件隔离。此次只生成设计和计划，不修改业务代码，不重新安装，不提交或推送。

验收覆盖无标题栏图片窗口、小截图/超宽/竖图和混合缩放、全部按钮、工具面板不落入导出图、录入取消/失焦/冲突回滚/重启保留、三个快捷键恢复及权限状态真实刷新。边界和未测项写入使用与验证记录。
