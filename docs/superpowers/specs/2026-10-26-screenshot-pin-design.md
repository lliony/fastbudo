# 截图与贴图第一批

用户已确认第一批范围。入口见[文档索引](../../README.md)，实施见[计划](../plans/2026-10-26-screenshot-pin.md)。

## 范围与验收

区域、窗口、全屏截图，多屏选择与 Retina 像素保留；复制、保存、一键贴图。标注包括矩形、椭圆、箭头、画笔、文字、马赛克、撤销/重做。贴图支持置顶、拖动、缩放、旋转、翻转、透明度、鼠标穿透、隐藏/恢复。菜单栏、设置、可配置截图与贴图快捷键、剪贴板历史图片右键贴图均接入。

## 实现边界

SwiftUI/AppKit 原生实现，无新增依赖。系统 screencapture 负责交互选区/窗口及屏幕截图，临时文件只写本任务专属目录，取消不改剪贴板，结束即清理。截图权限按需提示。编辑和贴图共享导出结果；NSPanel 不带出设置窗口。保存拒绝覆盖，图片解码和浮窗数量有上限。快捷键按事件 ID 分发；穿透恢复入口保留在菜单栏。复制是否进入历史沿用用户记录设置。

不包含控件识别、历史回放、取色、HTML/文本贴图、GIF、分组及重启恢复，不复制 Snipaste 程序或素材。

## 验证

先构建引擎，再运行 App 测试与 Release 构建。自动测试覆盖标注导出像素、撤销重做、图片变换、无覆盖保存、快捷键路由。多屏/混合缩放、录屏权限、全屏 Space 和穿透操作需单独记录真实系统验证，构建成功不能代替交互验收。
