# 截图 ESC 关闭与快速输出

来源：用户要求支持 ESC 快速关闭截图、快速截图并复制、快速截图并下载。实施见[计划](../plans/2026-10-27-screenshot-quick-actions.md)，返回[文档索引](../../README.md)。本设计已在开发工作区实现；验证与未测范围见[使用记录](../../guides/screenshot-pin.md)。尚未安装、合并或发布。

## 用户已确认的交互

快速操作使用区域截图：发起后用现有箭头指针选区，跳过标注编辑器。复制在松开鼠标后直接完成；下载在松开鼠标后弹出原生“另存为”对话框，由用户选择目录和文件名，确认后才保存 PNG。菜单及设置页提供入口，两种操作可分别录入快捷键。新快捷键初始为“未设置”，不得占用用户已有组合。这两项交互已由用户明确选择，不再采用自动保存到下载文件夹的默认方案。

## 全局约束

- Apple Silicon / macOS 27；Swift 6、SwiftUI/AppKit，不新增第三方依赖。
- AppKit 窗口与剪贴板操作留在主线程；图片编码、文件读写留在后台。
- 保留明亮中国红、原应用图标、现有区域选取层、原截图/贴图快捷键及现有偏好。
- 保留 20 MiB、单边 20000 像素、总计四千万像素及最多两个截图编辑器的边界。
- 输出 PNG 保留原图像素和方向，拒绝覆盖任何已有文件；取消选区不写剪贴板或输出文件。
- 测试仅使用合成图片、独立剪贴板和专用临时目录；不修改用户快捷键或测试用户文件。
- 当前截图工作区含大量未提交改动，不重置、不覆盖、不把旧历史合并或推送到主分支。
- 用户已选择子代理逐任务实施；不自动提交、安装、合并、推送或发布。

## ESC 的一致行为

普通截图编辑器获得输入焦点时，按一次 ESC 关闭当前截图，即使工具菜单打开或文字输入框正在编辑。其他截图、贴图、设置页与其他应用不得受到影响；不注册全局 ESC 快捷键。

截图选区阶段 ESC 继续取消本次选取。原编辑器的保存面板或错误提示占用模态焦点时，ESC 先执行该面板的取消/关闭语义，编辑器图片保留。快速下载的另存为面板中，ESC 等同取消本次保存，不写文件、不创建编辑器。已经确认的 PNG 编码或写盘不被 ESC 中断，完成后按现有成功关闭/失败保留规则处理。修改后的单次 ESC 关图规则取代旧[交互设计](2026-10-26-screenshot-interaction-design.md)中“先收起工具面板”的规则。快捷键录入器保持现有 ESC 可录入语义，不受截图局部监听影响。

## 快速输出行为

| 入口 | 选区完成 | 成功反馈 | 失败 |
|---|---|---|---|
| 区域截图 | 打开编辑器 | 沿用现有行为 | 沿用现有行为 |
| 截图并复制 | 验证图片后写 PNG 到剪贴板 | 不创建编辑器；状态显示“已复制截图” | 保留截图到编辑器供重试并显示原因 |
| 截图并下载 | 弹出另存为面板，确认后编码并无覆盖保存 PNG | 不创建编辑器；状态显示实际文件名 | 写盘失败保留截图到编辑器供重试；取消仅结束本次输出 |

另存为面板建议文件名为 `截图-<毫秒时间戳>-<UUID前8位>.png`，实际路径以用户选择为准；不强制系统下载目录，不新增目录偏好或导出格式。保存面板必须主动前置并获得键盘焦点；不得为显示保存面板重新打开设置页。取消选区或取消保存都不产生新输出，也不更改剪贴板。

保留按住 Control 松开鼠标直接复制：普通区域截图遇到 Control 转为复制；明确发起“截图并下载”时仍下载，修饰键不能偷偷改变已选输出目标。窗口截图保持现有系统选择流程，不扩展快速窗口/全屏模式。普通区域 Control 复制也走先校验、再写剪贴板的公共输出路径，避免与新入口重复写入。

保存面板等待确认期间也属于本次任务；确认前停止应用时取消面板并释放等待，不产生保存输出。一经确认进入既有 PNG 编码/写盘事务，就不再中途取消，停止后仍可能完成已确认的文件，但不得出现新的反馈窗口。截图/输出串行，繁忙时拒绝重复发起；输出目标随本次任务闭包传递，不使用可能被下一次截图改写的共享目标字段。停止后不得再写剪贴板、创建编辑器或弹取消错误；已经进入文件写入阶段的任务不删除已成功输出的文件。

## 快捷键和入口

Carbon 标识保留剪贴板 1、截图 2、贴图 3；新增复制 4、下载 5。新增偏好前缀 `screenshotCopy` / `screenshotDownload`，各使用 `Key`、`Modifiers`、`KeyLabel` 后缀。已有 `screenshot*`、`pin*` 偏好保持兼容。

四种截图/贴图组合之间，以及与已启用的剪贴板组合之间检查冲突。候选注册成功才保存；失败保留旧绑定。录入任意一项时暂停全部五个入口，松键/失焦/切页后恢复。允许清除两个新增绑定，清除不影响原截图/贴图绑定。总开关控制全部四种截图/贴图动作。

## 验收

1. 画布、工具面板、文字输入三种焦点下，一次 ESC 只关闭当前截图；保存面板取消后图片仍可操作；设置录入 ESC 不关图。
2. 复制成功保留 Retina 像素；下载必须先显示另存为面板，确认后实际落盘；取消无输出，已有文件保持原字节；两条快速路径成功时均不产生编辑器。
3. 取消、解码失败、写入失败、快速重复发起和停止期间的行为符合上文；失败截图可从恢复编辑器重试。
4. 两个新快捷键默认未设置、可以录入/清除/重启保留；五个入口事件隔离，冲突不覆盖旧配置。
5. 使用现有引擎构建、App 测试、独立 ClipboardLifecycle 回归及 Release 构建验证；记录多屏混合缩放、真实权限、保存面板和目标机器未测范围，不把单元测试当作实机证据。
