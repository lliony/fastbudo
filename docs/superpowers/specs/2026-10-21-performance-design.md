# 全功能性能与内存优化范围

[返回文档索引](../../README.md) · [两批实施计划](../plans/2026-10-21-performance.md)

本次由用户要求生成两批优化计划；尚未实施。审查基准为 `7fdd19a`，日期 2026-10-21。范围覆盖压缩、解压、Finder 新建与重命名、剪贴板、后台轮询与任务队列。设置、登录项和快捷键未发现值得重构的热循环，保留现状。

## 全局约束

- 保留 SwiftUI/AppKit、Swift 6、SQLite 和 7zip C++ 桥接，不新增框架或依赖。
- 实测基线为 Apple Silicon / macOS 27；Intel 和其他系统版本未验证，不声明实测兼容。
- 保留路径安全预检、O_NOFOLLOW、不可变输入快照、冲突保护、解压预算、取消及失败清理。
- 密码不得进入参数、环境变量、日志或临时文件；不得覆盖输入和已有输出。
- 压力、错误和迁移测试仅使用专用临时数据；剪贴板测试使用唯一 NSPasteboard，不读写用户剪贴板。
- 保留去重、最近使用排序、收藏保护、堆栈顺序、任意子串搜索和 v1 JSON 备份兼容性。
- 单条删除继续立即安全删除内容；数据库空间整理仅在手动清理时执行。
- 不推送、不发布、不自动修改系统权限；安装与重启不属于生成计划的授权范围。

## 审查证据与追溯

| 编号 | 批次及范围 | 当前证据 | 验收重点 |
|---|---|---|---|
| A1 | 第一批：异常日期 | 导入仅检查 finite；合成 used=-1e300、favorite=true 导入成功，显示天数转 Int 可溢出 | 导入整批回滚，旧库异常值显示不崩溃 |
| A2 | 第一批：压缩路径归并 | stage 存在两轮数组 contains；1000/3000 合成路径准备耗时 677.7/6112.4 ms | 去平方级扫描，保留路径边界与输出顺序 |
| A3 | 第一批：大文本转换 | 主线程 components/joined；5 MB 去空白 133.5 ms，独立进程峰值 RSS 114.5 MiB | 后台单次转换，保持 Unicode 空白语义 |
| A4 | 第一批：桥接条目与响应 | extract->items 复制 vector，解压输出完整清单却被 Swift 丢弃 | 单一条目所有者，小型成功响应，安全校验不减 |
| A5 | 第一批：隐藏面板刷新 | 每次采集无条件 list/groups/matchingIDs，重复 rebuildVisible | 隐藏只入库标脏，显示时刷新，过期结果不覆盖 |
| A6 | 第一批：Finder 新建 | 文件创建和 AX 树遍历在 MainActor | 文件 I/O 后台化，严守唯一目标核对 |
| B1 | 第二批：解压目录枚举 | 扫描排序全部邻居，目标 family 重复正则计算 | 减少重复计算，不能遗漏分卷 |
| B2 | 第二批：快照复制 | 创建和解压均完整复制，tar.gz 有中间 tar | 先测 APFS clone，保留普通复制回退 |
| B3 | 第二批：剪贴板存储 | capture/put 重复编码哈希；大 payload 与 meta 同行 | 先复用编码；拆表需独立收益及迁移门槛 |
| B4 | 第二批：过期搜索 | 180 ms 去抖和结果丢弃不取消已经启动的查询 | 合并排队请求；不误中断同连接写入 |
| B5 | 第二批：暂停唤醒 | 暂停后仍每 0.5 秒读取 changeCount | 暂停停 timer、保留热键、恢复跳过旧内容 |
| B6 | 第二批：结果历史 | results 无限增长，界面只展示 first | 内存保留最近 20 项，不删除输出文件 |

上述耗时是定位用单轮合成探针，不是主应用 P95/P99；RSS 是整个探针进程峰值而非净增量。历史 10 MiB payload 的 markUsed 约 105 MiB 峰值仅作拆表复测线索，不是当前应用基准。审查未运行百万条目归档、网络卷、Intel、长期泄漏或真实帧率测试。

## 两批边界与决策门槛

第一批修复确定缺陷和已确认的无用工作；第二批先落地简单局部改动，再评估成本较高的方案。所有收益在同机、同 Release 配置、同合成数据下至少独立运行 5 次，报告中位数、最差值和峰值 RSS，记录系统、磁盘和版本。耗时与内存分别测量，不能用单次测试推断泄漏。

B2：大文件或多小文件场景复制耗时中位数至少降低 20%，其他场景不退化超过 10%，且快照隔离、安全与回退验证全部通过，才采用 clone；否则记录结论并保留原实现。

B3：先做编码复用。拆表必须在 10 MiB 内容反复 markUsed/收藏场景获得至少 20% 的延迟或峰值 RSS 改善，另一指标不退化超过 10%，并通过原子迁移、故障回滚、备份兼容测试；未满足则不改 schema。

A6：先后台创建文件，AX 优化须证明不误发回车。若后台 AX 无法安全满足 Swift 并发约束，保留现有有界遍历并记录剩余主线程风险，不使用 unchecked Sendable 掩盖未验证的线程安全。

## 不纳入范围

不替换 UI 框架、不加缓存框架、不用硬链接代替快照、不用 FTS 替换任意子串搜索、不移除安全预检、不优化未测出的热路径。不承诺硬实时或固定帧率。
